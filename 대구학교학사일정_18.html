📖 사용 방법 & 링크 공유
🔗 링크 공유하는 방법
1️⃣ Netlify (가장 쉬움) ⭐
드래그앤드롭으로 가장 빠르게 배포됩니다.
① https://netlify.com 접속
② HTML 파일을 화면에 끌어다 놓기
③ 자동으로 생성된 링크 복사
④ 블로그나 카톡에 붙여넣기
✅ 무료, 매우 간단, 빠름
2️⃣ Vercel (이미 사용 중)
GitHub와 연동해서 자동 배포됩니다.
① https://vercel.com 접속
② GitHub 저장소 연결
③ 자동으로 배포되어 링크 생성
④ 파일 업데이트 시 자동 반영
✅ 무료, 자동 업데이트
3️⃣ GitHub Pages (무료)
GitHub 계정만 있으면 바로 배포됩니다.
① GitHub에서 새 저장소 생성
② index.html로 파일명 변경 후 업로드
③ Settings → Pages 설정
④ 자동 생성된 링크 사용
✅ 무료, 간단
4️⃣ Google Drive (가장 간단)
Google Drive에 올리고 공개 링크를 공유합니다.
① Google Drive에 파일 업로드
② 공개 링크 생성
③ 링크 복사해서 공유
⚠️ 브라우저 다운로드 페이지가 보임
💡 웹사이트 사용 방법
🔍 학교 찾기
왼쪽 사이드바에서 학교를 검색합니다.
• 학교명 입력: "동중", "정화중" 등
• 학교 유형 필터: 초등학교, 중학교, 고등학교
• 학교명 클릭하면 상세 정보 표시
⭐ 즐겨찾기 추가
자주 보는 학교들을 즐겨찾기에 추가합니다.
• 학교 옆의 별 버튼 클릭 (☆ → ⭐)
• 왼쪽 "⭐ 즐겨찾기" 섹션에 추가됨
• 첫화면에 즐겨찾기 카드로 표시
📅 달력 보기
각 학교의 월별 일정을 달력으로 확인합니다.
• 학교 선택 후 오른쪽에 달력 표시
• ◀ ▶ 버튼으로 월 이동
• 색깔별로 일정 종류 구분됨
🎓 일정 카드
선택한 학교의 주요 일정을 한눈에 봅니다.
• 시험 일정 (중간고사, 기말고사)
• 방학 (여름, 겨울)
• 졸업식, 교과서 정보
🏠 첫화면으로
언제든지 처음 화면으로 돌아갈 수 있습니다.
• 상단 오른쪽 "🏠 첫화면" 버튼 클릭
• 첫화면의 즐겨찾기 카드들 다시 표시
